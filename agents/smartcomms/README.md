# SmartComms

Agente baseado em prompt para adaptar briefings a diferentes canais de comunicação corporativa em inglês.

## Capacidades presentes no prompt

- Papéis conceituais de estratégia, copywriting, UX writing e validação.
- Versões para e-mail, Teams, Viva Engage e mensagens corporativas.
- Recomendação de canal, validação de CTA, prazo e prontidão textual.
- Tradução e adaptação de entradas para inglês corporativo.

## Limitações e status

Os quatro papéis não comprovam uma arquitetura multiagente. O agente produz conteúdo destinado aos canais, mas não demonstra publicação ou integração com eles.

**Status:** prompt em inglês documentado. Testes: **planejados — não executados**.
