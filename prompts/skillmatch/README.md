# SkillMatch

Agente baseado em prompt para apoiar a triagem de currículos contra os requisitos de uma vaga.

## Capacidades presentes no prompt

- Extração de requisitos técnicos e profissionais.
- Avaliação individual de cada currículo exclusivamente contra a vaga.
- Pontuação conceitual, justificativas, pontos fortes e lacunas.
- Ordenação posterior das pontuações independentes.

## Limitações e status

A fórmula de pesos ainda não foi validada. Soft skills não devem ser inferidas sem evidência textual. A recomendação apoia R&S e exige revisão humana.

**Status:** prompt documentado. Aplicação e integração ATS não comprovadas. Testes: **planejados — não executados**.
