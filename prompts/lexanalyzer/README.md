# LexAnalyzer

Protótipo de agente interno para consolidar e estruturar informações provenientes de diferentes fontes, aplicando critérios fornecidos pela organização e encaminhando o resultado para validação humana.

## Capacidades presentes no prompt

- Consolidação de fontes textuais.
- Identificação de lacunas e divergências.
- Explicação das regras acionadas.
- Encaminhamento de situações incompletas para revisão.

## Limites e status

Não substitui R&S, Jurídico ou Proteção de Dados e não deve tomar decisões autônomas de contratação. A versão pública não reproduz critérios internos literais, dados judiciais, CPF, URLs ou nomes de sistemas.

**Status:** prompt restrito; versão pública sanitizada. Testes: **planejados — não executados**.
