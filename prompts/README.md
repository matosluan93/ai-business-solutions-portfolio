| Projeto | Aplicação do prompt | Entrega pública |

| [SmartComms](smartcomms/) | Comunicação corporativa | Prompt em inglês com adaptação por canal |
| [SpeakAI](speakai/) | Tutoria de idiomas | Prompt e desenho de jornada |

| [SkillMatch](skillmatch/) | Comparação assistida de currículo e vaga | Critérios e formato de resposta |

**Escopo:** esta seção documenta prompts. Interfaces e integrações implementadas são apresentadas na seção [Aplicações](../applications/). A execução do TalentHub e a interface do SpeakAI têm páginas próprias.
