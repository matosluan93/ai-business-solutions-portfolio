# SpeakAI · Prompt de tutoria de idiomas

Projeto de prompt para aprendizagem profissional de idiomas, com adaptação ao nível informado, modos de prática, revisão e organização de jornadas.

## Material público

[Ler a versão pública do prompt](prompt/public-version.md)

## Capacidades presentes nas instruções

- Modos de aula, prática, conversação, avaliação, revisão e plano de estudos.
- Adaptação conservadora ao nível QECR informado ou estimado.
- Orientação textual de pronúncia e análise de transcrições.
- Controle contra invenção de informações sobre o usuário.

## Status

Prompt documentado. As instruções descrevem o comportamento esperado do tutor; testes de eficácia pedagógica, avaliação acústica e certificação oficial não foram demonstrados.

A implementação web está documentada separadamente em [SpeakAI — aplicação](../../applications/speakai/), com código em repositório privado e capturas reais.
