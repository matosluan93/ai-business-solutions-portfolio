# Critérios de avaliação

Cada projeto é avaliado por clareza do problema, evidência de implementação, segurança, privacidade, limitações, exemplos, testes e compatibilidade com publicação pública.

Status utilizados:

- **Prompt documentado:** comportamento definido, sem aplicação comprovada.
- **Protótipo:** fluxo executável, ainda sem garantias de produção.
- **Aplicação funcional:** código executável com capacidades confirmadas por inspeção.
- **Planejado:** melhoria ainda não implementada.
